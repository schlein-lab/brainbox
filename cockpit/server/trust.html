Brainbox · Sicheres Zertifikat

Diese Brainbox als vertrauenswürdig einrichten

Deine Brainbox verschlüsselt alles mit HTTPS — nur kennt dein Gerät die hauseigene Zertifizierungsstelle der Box noch nicht, deshalb die Warnung „nicht sicher“. Einmal das Box-Zertifikat installieren, und die Warnung ist auf diesem Gerät für immer weg — komplett offline, ohne fremde Dienste.

⬇ Box-Zertifikat herunterladen
Fingerabdruck (zur Kontrolle, dass es wirklich deine Box ist):
%FINGERPRINT%

🤖 Android

  1. Datei oben herunterladen.
  2. Einstellungen → Sicherheit → Mehr → Verschlüsselung & Anmeldedaten → Zertifikat installieren → CA-Zertifikat.
  3. Die Datei brainbox-ca.crt auswählen, Warnung bestätigen.

iPhone / iPad

  1. Datei in Safari öffnen → „Profil laden erlauben“.
  2. Einstellungen → Allgemein → VPN & Geräteverwaltung → Profil „Brainbox Root CA“ → Installieren.
  3. Einstellungen → Allgemein → Info → Zertifikatvertrauens­einstellungen → „Brainbox Root CA“ einschalten.

🪟 Windows

  1. Datei doppelklicken → Zertifikat installieren → Lokaler Computer → Alle Zertifikate in folgendem Speicher: Vertrauenswürdige Stammzertifizierungsstellen.

macOS

  1. Datei doppelklicken → Schlüsselbund öffnet → im Schlüsselbund System ablegen.
  2. Doppelklick auf „Brainbox Root CA“ → Vertrauen → Bei Verwendung dieses Zertifikats: Immer vertrauen.

🐧 Linux / Firefox

  1. System: sudo cp brainbox-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates
  2. Firefox (eigener Speicher): Einstellungen → Datenschutz → Zertifikate → Zertifikate anzeigen → Importieren → „Dieser CA vertrauen, um Websites zu identifizieren“.

Fertig. Danach zeigt der Browser das grüne Schloss für diese Box — auf diesem Gerät dauerhaft. Für weitere Geräte diesen Schritt einmal wiederholen.
